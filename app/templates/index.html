1. 学习目标

这一部分不是单纯介绍页面功能，而是一份从零开始的实战指南。 目标是：从 Windows 安装 WSL2 开始，一步一步完成 Linux 开发环境搭建、 Python 虚拟环境配置、FastAPI 最小接口编写、以及用 Python 代码调用大模型接口。 在开始之前，可以去阿里云百炼平台，免费获取一个API KEY 来使用，激活右下角的AI助手，以便随时询问。 因为开发的较为仓促，目前是只测试过千问，其他不知道哦，大佬们可以自己更改这个项目。

学完后你应该能做到：

1）在 Windows 上正常使用 WSL2；
2）在 WSL 中创建 Python 项目；
3）跑通一个最小 FastAPI 后端；
4）写出一段访问大模型的 Python 代码；
5）理解这个项目为什么要用 FastAPI + API 调用的方式组织功能。

2. Windows 安装 WSL2

在 Windows 10 2004 及以上，或 Windows 11 中，可以直接用管理员权限打开 PowerShell， 执行下面这条命令安装 WSL。默认会安装 Ubuntu，安装完成后需要重启电脑。:contentReference[oaicite:2]{index=2} 

wsl --install

如果系统里已经安装过 WSL，可以先查看可安装的发行版，再按名称安装。安装完成后， 首次打开 Ubuntu 会提示你创建 Linux 用户名和密码。安装完成后，也可以用下面这条命令确认 当前发行版是否运行在 WSL 2 上。:contentReference[oaicite:3]{index=3} 

wsl --list --online
wsl --install -d Ubuntu
wsl --list --verbose
建议：

如果你后续主要在 WSL 的 Linux 命令行里开发，项目目录尽量建在 /home/你的用户名/项目名，而不是 /mnt/c/...。 微软官方建议把 Linux 命令行开发用的项目放在 WSL 自己的 Linux 文件系统里，以获得更好的性能。:contentReference[oaicite:4]{index=4}

3. 初始化 Linux 开发环境

进入 Ubuntu 之后，先更新软件源，并安装 Python、虚拟环境、pip 和 Git。 这里的命令是你后面做 Python 后端开发最常用的一组基础命令。 

sudo apt update
sudo apt install -y python3 python3-venv python3-pip git

然后创建一个真正放在 Linux 文件系统里的项目目录，例如： 

mkdir -p ~/llm-projects/fastapi-llm-demo
cd ~/llm-projects/fastapi-llm-demo

如果你想从 WSL 里直接打开当前目录到 Windows 资源管理器，也可以执行： 

explorer.exe .

4. 创建项目与虚拟环境

Python 项目建议一开始就使用虚拟环境。这样不同项目的依赖不会互相污染， 后续排查问题也更方便。 

python3 -m venv .venv
source .venv/bin/activate

激活成功后，终端前面通常会出现 (.venv) 标记。 接着安装本次实战要用到的依赖： 

pip install fastapi uvicorn openai python-dotenv
说明：

FastAPI 用来写后端接口，Uvicorn 用来启动 ASGI 服务，OpenAI Python SDK 用来发起大模型请求， python-dotenv 用来从 .env 文件读取密钥，更适合本地学习场景。OpenAI 官方 SDK 文档也建议把密钥放在环境变量或 `.env` 中，而不是直接写进源码。:contentReference[oaicite:5]{index=5}

5. 写第一个 FastAPI 接口

先不要一上来就把整个项目都写复杂。建议先写一个最小的 FastAPI 应用， 确认“后端服务能启动、浏览器能访问、接口能返回 JSON”。 FastAPI 官方最小示例如下： 

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}

你可以把这段代码保存到 main.py。

6. 启动服务并测试接口

FastAPI 官方文档给出了 fastapi dev 的开发模式用法， Uvicorn 官方文档则给出了 uvicorn main:app 的启动方式。对于入门项目， 直接用 Uvicorn 启动非常直观。 

uvicorn main:app --reload

启动成功后，浏览器访问： 

http://127.0.0.1:8000

如果页面能看到返回的 JSON，说明你的最小后端已经跑通。

7. 用代码访问大模型

接下来把“普通后端接口”升级成“能访问大模型的后端接口”。 OpenAI 官方 Python SDK 支持 Python 3.9+，安装命令是 pip install openai， 也支持通过 api_key 和 base_url 创建客户端。对于 OpenAI 兼容接口的大模型服务， 这种写法非常适合作为入门示例。 API可以去阿里百炼平台免费获取，用于自己的初次开发，一定要注意密钥千万别泄露，万一泄露，抓紧删除再重建一个！

先创建一个 .env 文件：

API_KEY=你的模型密钥
BASE_URL=你的模型服务地址
MODEL_NAME=你的模型名称

然后写一个最小调用示例，例如保存为 test_llm.py：

import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.getenv("API_KEY"),
    base_url=os.getenv("BASE_URL")
)

completion = client.chat.completions.create(
    model=os.getenv("MODEL_NAME"),
    messages=[
        {"role": "system", "content": "你是一个耐心、清晰的学习助手。"},
        {"role": "user", "content": "什么是 FastAPI？"}
    ]
)

print(completion.choices[0].message.content)

这段代码的核心意义是：你已经不再只是“启动一个后端”，而是学会了“让 Python 代码向大模型服务发请求并拿回结果”。 这正是后面做聊天助手、提示词工程工具、AI 页面交互的基础。

8. 把最小示例接入当前项目

当你已经跑通最小示例后，再回到当前项目，就更容易理解它的结构了：

  • 前端页面：负责输入问题、显示消息、展示会话容器和设置页。
  • FastAPI 路由：负责接收前端请求，例如聊天请求、读取会话列表、保存配置。
  • llm_service：负责真正调用大模型接口。
  • history_service：负责保存和读取会话容器。

也就是说，你当前这个项目其实就是在“最小 FastAPI 示例”的基础上， 多加了：

会话记录保存
API Key 配置管理
前端聊天页面
多轮会话上下文
